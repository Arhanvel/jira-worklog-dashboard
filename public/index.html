    Jira instances

      Type
      Auth method

      For a Basic-auth gateway (e.g. nginx auth_basic) in front of Jira. With session login these go in the Authorization header (often the same as your Jira username/password); with token/Basic Jira auth they fall back to Proxy-Authorization.

      Hourly rates

      Global rate with per-project overrides. Money is computed locally — nothing is sent to Jira.

      per-project overrides

      Leave a project blank to use the default rate. Applies across all instances.

        Earnings goal

        How much do you want to earn in the range you're viewing? The summary then shows what's left, how many work days (Mon–Fri) remain in the range, and the average hours per day you'd need to track to get there.
